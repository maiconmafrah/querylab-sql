Você precisa listar os clientes que nunca fizeram um pedido. A coluna pedidos.cliente_id aceita NULL (compras de convidados). Qual consulta devolve o resultado correto?

clientes (cliente_id, nome, uf) pedidos (pedido_id, cliente_id, valor)
A
SELECT c.nome FROM clientes c WHERE c.cliente_id NOT IN (SELECT cliente_id FROM pedidos);
B
SELECT c.nome FROM clientes c LEFT JOIN pedidos p ON p.cliente_id = c.cliente_id WHERE p.pedido_id IS NULL;
C
SELECT c.nome FROM clientes c JOIN pedidos p ON p.cliente_id = c.cliente_id WHERE p.cliente_id IS NULL;
D
SELECT c.nome FROM clientes c LEFT JOIN pedidos p ON p.cliente_id = c.cliente_id AND p.pedido_id IS NULL;
